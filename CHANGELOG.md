# Changelog

## 0.5.0 - 2026-07-21

### Added
- Multi-query company discovery with location and remote variants.
- Domain-level deduplication and exclusion of job boards/social networks.
- Configurable discovery limits and concurrency.
- Discovery run history and campaign score thresholds.
- Campaign deletion, remote-only campaigns and structured discovery API.

## 0.4.0 - 2026-07-21

### Added
- Environment-based settings and `.env.example`.
- Rotating application logs and centralized exception handling.
- Alembic database migrations.
- Database initialization, seed and SQLite backup commands.
- Pytest suite and GitHub Actions workflow.
- Health endpoint and application version metadata.
